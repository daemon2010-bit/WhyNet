# Глобальный аудит сети, операторов, ТСПУ и AdGuard/VPN (WhyNet v2.0+)
# Как запустить:
#   1. Откройте WhyNet -> Утилиты -> Дополнительно -> Сценарий (.txt)
#   2. Нажмите «Загрузить файл» и выберите этот файл (WhyNet-Global-Audit.txt)
#   3. Укажите тег среды (например: Дом Wi-Fi + AdGuard, МТС 4G, МегаФон 4G + VPN)
#   4. Нажмите «Запустить сценарий» (займёт примерно 3-4 минуты)
#   5. Повторите прогон на второй сети (Wi-Fi и мобильный интернет)
#   6. Перейдите в «История» (вверху на главном экране) -> отметьте отчёты или нажмите «Отправить все отчёты» (ZIP)
