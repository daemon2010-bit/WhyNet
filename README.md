# WhyNet

Android-приложение для комплексной диагностики мобильной и Wi-Fi сети, визуализации пути пакета и анализа радиоэфира без root-доступа.

## Основные возможности

### 1. Диагностика сети (вкладка «Сеть»)
- **Живая телеметрия**: тип сети (`Wi-Fi 4/5/6` или `4G+/5G`), IPv4, внешний IP, DNS, базовая станция (`eNB`, диапазон LTE, RSRP) или канал/сигнал/PHY-скорость Wi-Fi, детекция VPN/фильтра, CGNAT, загруженности канала и живой 2-кривый спарклайн трафика.
- **Визуальная схема «Путь пакета (7 этапов)»**: `Телефон - Роутер/Вышка - DNS / Связь (TCP) - Защита (TLS) - Сервер (HTTP) + ветка Звонки/Игры (UDP/STUN)`. На стрелках показана дельта задержки этапа (`+мс`), внутри узлов - суммарная задержка до точки.
- **Автоматический вердикт и рекомендации**: определяет локальные проблемы Wi-Fi (включая перегрузку канала), подмену DNS, обрывы TCP/TLS/SNI, фильтрацию по порогу 16 КБ, ограничения UDP/NAT.
- **Контуры доступности**: быстрая проверка ключевых контуров (`РФ`, `CloudFront`, `Cloudflare`, `UDP STUN`).
- **История и экспорт**: локальный журнал проверок, сравнение «До / После» и экспорт всех отчётов и логов в один ZIP-архив.

### 2. Wi-Fi Анализатор (вкладка «Wi-Fi»)
- **Факторы скорости Wi-Fi**: стандарт, диапазон, ширина канала, PHY-скорость `↓/↑ Мбит/с` и оценка узких мест.
- **Спектр каналов (2.4 / 5 / 6 ГГц)**: градуированный график `-30..-100 дБм` с подсветкой свободных каналов, списком источников помех и рейтингом всех каналов диапазона.
- **Список сетей**: полный BSSID, встроенная офлайн-база производителей (OUI), частота МГц, центральный канал, 5-сегментная шкала сигнала, дистанция, `11k/v/r`, сортировка по сигналу/каналу/SSID/вендору.
- **Тепловая карта помещения**: квадратная сетка `1 клетка = 1 м`, строго ортогональное рисование стен по сетке, готовые шаблоны планировок, загрузка фото плана, IDW-интерполяция сигнала и пинга шлюза, оценка расположения точек доступа и экспорт в PNG.
- **Живой замер сигнала (1 Гц)** и **LAN-сканер** устройств в подсети.

### 3. Сетевые утилиты (вкладка «Утилиты»)
- **Тест ТСПУ / Белые списки** (SNI, порог 16 КБ, CloudFront, Cloudflare, Google, YouTube, Discord).
- **Задержка сервисов** - живой монитор RTT по 8 ключевым сервисам с автообновлением каждые 2 с.
- **Проверка массовых DNS** (системный, Яндекс, 1.1.1.1, 8.8.8.8, Quad9, AdGuard, OpenDNS).
- **Пинг и монитор обрывов** (фоновый сервис с уведомлением и быстрой кнопкой остановки).
- **Трассировка с выводами**, **Домен / IP (DNS + WHOIS)**, **Сканер TCP-портов**, **Скорость и Bufferbloat** (2-кривый график скорости и пинга под нагрузкой).
- Дополнительно: проверка отдельного приложения, пакетный прогон сценариев `.txt`, Wake-on-LAN, IP/CIDR калькулятор, поиск MTU, UDP/STUN, двойной SNI/TLS.

## Требования и сборка

- Android 12+ (`minSdk = 31`, `targetSdk = 36`)
- JDK 21, Android SDK

```bash
# Прогон юнит-тестов ядра диагностики
./gradlew :core:engine:runEngineUnitTests

# Сборка Release APK
./gradlew :app:assembleRelease
```
